# Facebook Agent Action API

This module provides a REST API wrapper around the Facebook scraping module, turning it into a set of **Agentic Actions**. It is built using FastAPI, making it natively compatible with Agent architectures (like LangChain, AutoGen, or OpenAI function calling) because it automatically exposes a standard OpenAPI/Swagger schema.

## Features

The API maintains a persistent, stateful browser session in the background and provides endpoints to manipulate it:
- **Search & Scrape**: Search for a query and scrape the resulting posts.
- **Scrape URL**: Navigate to any Facebook URL (group, profile, company) and scrape posts.
- **Scrape Home**: Scrape the authenticated user's home feed.
- **Action/Click**: Click elements on the current page using text matching or CSS selectors (useful for an agent trying to expand comments, close modals, or navigate).

## Setup

Ensure your dependencies are installed (specifically `fastapi` and `uvicorn`, which have been added to the root `requirements.txt`).

1. Install dependencies:
   ```bash
   pip install -r ../requirements.txt
   ```
2. Make sure your `.env` file in the root directory contains your Facebook credentials:
   ```env
   FACEBOOK_EMAIL=your_email@example.com
   FACEBOOK_PASSWORD=your_password
   ```

## Running the Server

Start the API server from the root of the `scrapers` project (or inside this directory):

```bash
cd facebook_agent_api
python server.py
```

The API will be available at `http://127.0.0.1:8000`. 
You can view the interactive OpenAPI documentation at `http://127.0.0.1:8000/docs`.

## API Endpoints

All endpoints accept JSON payloads. The browser will automatically initialize and log in upon the first request that requires it.

### 1. Initialize Browser `[POST /api/init]`
Forces the browser to start and log in. (Optional, as other endpoints will auto-initialize).
**Response:** `{"status": "success", "message": "Browser initialized and logged in."}`

### 2. Search and Scrape `[POST /api/scrape/search]`
Searches for a query and scrapes the posts.
**Payload:**
```json
{
  "query": "Machine Learning",
  "max_posts": 10,
  "max_scrolls": 10
}
```

### 3. Scrape URL `[POST /api/scrape/url]`
Navigates to a specific URL and scrapes posts.
**Payload:**
```json
{
  "url": "https://www.facebook.com/groups/somegroup",
  "max_posts": 10,
  "max_scrolls": 10
}
```

### 4. Scrape Home `[POST /api/scrape/home]`
Scrapes the user's home feed.
**Payload:**
```json
{
  "max_posts": 10,
  "max_scrolls": 10
}
```

### 5. Click Element `[POST /api/action/click]`
Clicks an element on the current page. The agent can use this to interact with the DOM dynamically.
**Payload (By Text):**
```json
{
  "text": "See more"
}
```
**Payload (By Selector):**
```json
{
  "selector": "div[aria-label='Close']"
}
```

## Agent Integration

If you are using an LLM framework like LangChain, you can easily load these endpoints as tools:

```python
from langchain.agents.agent_toolkits.openapi.spec import reduce_openapi_spec
from langchain.requests import RequestsWrapper

# The agent can automatically read the OpenAPI spec generated by FastAPI
# at http://127.0.0.1:8000/openapi.json and convert them into tools.
```
Or simply wrap the `requests.post("http://127.0.0.1:8000/api/scrape/search", json={"query": "..."})` calls inside your Python tool definitions.
